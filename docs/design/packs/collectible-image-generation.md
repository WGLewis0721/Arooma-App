# Pack: Archive Foil collectible image generation (locked v3)

> Part of the Arooma design brain. Start at [../README.md](../README.md). For standalone collectible art **only**; ordinary cabinet UI stays governed by [shelf-change.md](shelf-change.md).

**Visual master:** the final approved 2026-10-30 DIOR SAUVAGE ELIXIR diptych **with visible grapefruit and top notes on the front, no separate ULTRA RARE tier, and the exact three-horizontal-strip back layout**. The prior Prodigy and Prada examples are historical and no longer the default reference. Use the owner-provided approved image as optical source, but never use AI-generated image text as product facts.

## Quick task definition

- Build **two separate 59:86 front/back images**, 1180×1720 px working size, with optional diptych proof.
- Keep authentic bottle silhouette/label, editorial original photographic set, directional light, narrow multicolor engraved foil border, physically grounded props.
- **Front:** name and brand at top; **official concentration upper right**; **3-4 verified top-note names and recognizable top-note ingredient photo at the front**; dominant bottle; Arooma maker footer. **Never add standalone rarity badge.**
- **Back:** same house/name/concentration hierarchy; short italic description; **TOP / HEART / BASE as three horizontal ingredient photograph strips with note names to the right**; bottom row year / positioning / concentration; Arooma footer. Keep precise serif/italic/copper spacing; not three side-by-side mini cards.
- Human designer supplies all readable lettering and separate foil vector mask; AI produces photographic plates, not an uneditable final card.
- Source all product facts from the **exact manufacturer's concentration/version**; release dates and note pyramids must be checked individually. If unverified omit. Public brand/photo use requires rights review.

- [ ] Top-note visual and 3-4 source-verified top notes appear **on front**; back repeats same list.
- [ ] Concentration correctly labeled, including variants and official maker classification.
- [ ] **No** “ULTRA RARE”, stars or separate rarity status.
- [ ] Back: three horizontal image strips + right-hand note text; exactly three bottom fact fields.
- [ ] Realistic authentic product, controlled props, original image composition, disciplined foil treatment.
- [ ] Legible accurate typography and spelling. All metadata source-verified.
