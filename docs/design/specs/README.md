# Specs

> Part of the Arooma design brain. Start at [../README.md](../README.md).

Plans and spec sheets for Arooma requests live here, one file per request, named `YYYY-MM-DD-<short-slug>.md`. Write each from [TEMPLATE.md](TEMPLATE.md) by following [../PLAN_SPEC_PROTOCOL.md](../PLAN_SPEC_PROTOCOL.md).

A spec is a plan, not approval. When its decisions land, update the governing documents and the decision log in [../DECISIONS.md](../DECISIONS.md), and mark the spec Approved or Superseded.
